# יום צילום — דף נחיתה

דף נחיתה עצמאי להצעת **יום הצילום** (5 שעות, 1,499 ₪, 5 מקומות).
נפרד לחלוטין מדף הסוכנות שרץ ב-`adir-delta.vercel.app`.

אתר סטטי — אין שלב בנייה, אין תלויות. מה שיש בתיקייה זה מה שעולה לאוויר.

```
index.html        הדף עצמו
style.css         העיצוב (משותף עם privacy.html)
script.js         טפסי הלידים, באנר עוגיות, הסרגל הדביק בנייד
a11y-widget.js    תפריט הנגישות
adir.webp         התמונה בסקשן "מי אני"
privacy.html      מדיניות פרטיות
worker/           ה-Worker של Cloudflare שמקבל את הלידים
```

## ⚠️ חובה: לפתוח את ה-Worker לדומיין החדש

הטפסים שולחים לידים ל-Worker בכתובת:

```
https://adir-lead-intake.adirpagelior.workers.dev/submit-lead
```

ה-Worker בודק מאיזה דומיין הגיעה הפנייה, **ומאשר רק דומיינים ברשימה**.
בלי השלב הזה כל ליד מהדף הזה יידחה עם 403 — הדף ייראה תקין, והלידים פשוט לא יגיעו.

הקוד כאן כבר מתוקן לתמוך בכמה דומיינים (`ALLOWED_ORIGIN` מופרד בפסיקים).
אחרי שהדף עולה לאוויר וידוע לך הדומיין שלו:

```bash
cd worker
npx wrangler deploy
npx wrangler secret put ALLOWED_ORIGIN
```

וכשהוא מבקש את הערך, להדביק את **שני** הדומיינים, בלי רווחים:

```
https://adir-delta.vercel.app,https://<הדומיין-החדש>
```

זה ה-Worker היחיד שמשרת את שני הדפים — עדכון כאן משפיע גם על דף הסוכנות,
ולכן הדומיין הישן חייב להישאר ברשימה.

## תחזוקה שוטפת

**מונה המקומות** מופיע בשני מקומות ב-`index.html` ומתעדכן ידנית —
בסקשן האחריות ובסרגל הדביק. לחפש `נותרו` ולעדכן את שניהם יחד.

כשכל 5 המקומות נמכרים: או להוריד את הדף, או להעלות מחיר ולפתוח מחזור חדש.
מונה שתקוע על אותו מספר לאורך זמן עולה באמון בדיוק אצל הקהל שהדף מנסה למשוך.

**האייקונים** הם ליגטורות של Material Symbols — כותבים `movie` ומקבלים סמל.
הם מוסתרים עד שהפונט נטען, כדי שלא יוצג שם האייקון כטקסט.
